# 网页控制

[返回 README](../README.md)

## 启动与配置

按 README 构建后启动 `control.launch.py`。它启动 USB 桥接和控制器，需要连接真实底盘；不需要定位、IMU 或自动实验服务。

默认配置：[control.yaml](../src/ares_prerobot_test/config/control.yaml)。要使用其他配置：

```bash
ros2 launch ares_prerobot_test control.launch.py config:=/绝对路径/控制配置.yaml
```

修改配置后重启 launch。相对 `bag_directory` 按启动进程时的工作目录解析，建议从项目根目录启动，或在配置中填写绝对目录。

## 参数与按钮

| 输入 | 含义与单位 |
|---|---|
| `vx / vy` | 平面目标速度，m/s；限幅按平面速度向量模长检查 |
| `wz` | 目标角速度，rad/s |
| `amax` | 平面加速度上限，m/s² |
| `jerkmax` | 平面 jerk 上限，m/s³ |

角加速度和角 jerk 分别使用配置中的 `angular_accel`、`angular_jerk`。这些参数控制上位机生成的目标，不会修改固件限幅或电机电流限制。各项运动限值以配置文件为准。

| 操作 | 行为 |
|---|---|
| 取得控制权 | 取得唯一控制租约；此时不发送运动目标、不开始录包 |
| 发送目标 | USB 就绪后接受目标，生成受限速度序列；首次发送前创建录包 |
| 受限减速 | 使用当前加速度和 jerk 参数降至零，完成后停止发送；继续录包 |
| 立即零目标 | 发送 5 帧零目标，停止发送后约 0.2 秒关闭录包 |
| 释放控制 | 停止发送并结束录包；该操作自身不会发送零目标 |

同一时刻只有一个网页或 CLI 持有控制权。网页每 0.4 秒续租，默认租约 1.5 秒；失去租约或运行中 USB 链路失效时停止发送。USB 发送失败后桥接锁定为未就绪，需重启桥接。停止发送不等于车体已停车；下位机速度帧和心跳超时行为须按实际固件核对。

## 实时曲线

- v/a/j 图：实线为控制器实际发布的平面速度模及其导数，虚线为所选驱动轮 RPM 换算的轮缘速度模及其导数。它们不是车辆定位测得的地速。
- 轮速换算使用 `wheel_radius`（默认 0.04 m）和 `wheel_rpm_ratio`（默认 1）；实车参数不同应调整。
- 加速度与 jerk 使用约 0.24 秒的因果拟合窗口，导数点位于窗口中心，约有半个窗口的延迟。
- 电流图分别展示所选轮组的 Is 转向电流、Id 驱动电流，以及同次采样的四组均值。缺少任一组数据时不绘制对应均值。
- 页面每 100 ms 拉取增量数据，保留最近 30 秒；完整记录见 rosbag。

网页遥测使用 `chassis_speed_test` 固件的 `0x0131`（11 float 转速包）和 `0x0141`（10 float 电流包）。仓库中旧的 15 float 遥测补丁与网页转速格式不兼容。当前 VESC 负电流换算仍待固件驱动修正。

## 远程访问

控制器默认只监听机器人本机 `127.0.0.1:8766`。在自己的电脑建立 SSH 转发：

```bash
# 替换登录用户名和机器人地址；已有相同转发时无需重复建立
ssh -N -L 8766:127.0.0.1:8766 用户名@机器人地址
```

再用自己电脑的浏览器访问 http://127.0.0.1:8766/。

## CLI 控制

保持 `control.launch.py` 运行，另一终端进入项目根目录并加载同一 ROS 和工作区环境：

```bash
source /opt/ros/humble/setup.bash  # Ubuntu 24.04 使用 jazzy
source install/setup.bash
ros2 run ares_prerobot_test chassis_cli
```

输入五个数 `vx vy wz amax jerkmax`，或输入 `status / stop / halt / quit`。CLI 与网页共用控制器和录包机制，需要先释放网页控制权。`quit` 会请求零目标再释放控制；`Ctrl+C` 仅中断并释放控制，不主动发送零目标。
